# ドキュメントの更新（2019 年） {#documentation-updates}

2019 年に新しく、または改訂版としてリリースされたドキュメントのリスト。 Experience Cloud リリースノートで扱われていない可能性のある、Audience Manager ドキュメントの細かな更新が含まれています。

[!DNL Audience Manager] とその他の [!DNL Experience Cloud] ソリューションの変更点については、[Experience Cloud リリースノート](https://experienceleague.adobe.com/docs/release-notes/experience-cloud/current.html?lang=ja)を参照してください。 以前のリリースノートについては、[以前の年度](../docs-updates/docs-2018.md)節を参照してください。

## 2019 年 11 月 {#aam-november-updates}

| トピック | 説明 |
|--- |----|
| [カリフォルニア州消費者プライバシー法（CCPA）のサポートとプライバシーに関するドキュメントの調査](../overview/data-security-and-privacy/data-privacy.md) | 2020 年 1 月 1 日（PT）に施行される[カリフォルニア州消費者プライバシー法（CCPA）](https://www.caprivacy.org/about)は、カリフォルニア州在住者に対して個人情報に関する新たな権利を提供し、カリフォルニア州で事業をおこなう特定の事業者に対してデータ保護責任を課します。 <br> <br>Audience Managerは、[Adobe Experience Platform Privacy Service](https://docs.adobe.com/content/help/ja-JP/experience-platform/privacy/home.html)などのプライバシーツールを通じて、データへのアクセス要求とデータ削除要求に対するプライバシー規制に基づく義務の遵守を支援します。<br><br> 現在の[ オプトアウト管理](../overview/data-security-and-privacy/data-privacy-requests.md#opt-out-requests) プロセスを更新して、宣言されたID （CRM IDなど）のオプトアウトを含めました。 宣言された ID によるオプトアウトの場合、宣言された ID と最後にリンクされたデバイスは、Audience Manager のデータ収集からオプトアウトされます。 オプトアウトリクエストは、この機能をサポートする[宛先パートナー](../overview/data-security-and-privacy/assets/AAM-Partners-October2019.xlsx)にもセグメント解除リクエストを一括およびリアルタイムで送信できるようになりました。<br><br> さらに、前述の規制に準拠するために必要な情報を簡単に見つけることができるように、[ データセキュリティ ](../overview/data-security-and-privacy/data-security.md)、[ データプライバシー](../overview/data-security-and-privacy/data-privacy.md)、[ データガバナンス ](../overview/data-security-and-privacy/data-governance.md)のドキュメントを再設計しました。 |

| [グローバルデータソース](../features/global-data-sources.md) | グローバルデータソースにはすべての Audience Manager ユーザーがアクセスでき、Apple、Samsung、Microsoft、Roku、Android などのデバイスのメーカーによって生成されたデバイス広告 ID が含まれています。 これらの ID は、メーカーが広告目的での利用を許可したものです。 グローバルデータソースを使用すると、デバイス ID を同期し、これらのマッピングでキーにされたデータを読み込みまたは書き出しできます。 Audience Manager では、ユーザーが読み込んだデバイス広告 ID（DAID）の形式が、デバイスの製造元が指定した標準形式と一致しているかを検証します。 |
