# Audience Marketplace optimization {#audience-marketplace-optimization}

Adobeは、Audience Marketplaceを強化し、アクティブなフィードを持つデータプロバイダーの可視性を向上させます。

このプロセスでは、現在使用されていないデータプロバイダーを削除しています。 最適化により、これらのデータプロバイダーが提供する特性も取り除かれます。 このプロセスは、マーケットプレイスを合理化し、すべてのユーザーの全体的なパフォーマンスを向上させるように設計されています。

**タイムライン：** データプロバイダーは、2025年8月に削除されます。

## 現状 {#what-changes}

Audience Managerのエクスペリエンスの向上を続けながら、特にデータパートナーに関して、Audience Marketplaceを最適化しています。

## ビジネスへの影響 {#impact}

この最適化は、現在のデータプロバイダーの関係や利用可能なデータソースに影響を与える可能性があります。 アドビは、次のことを推奨します。

1. **現在のデータプロバイダーを確認**：アクティブに使用しているプロバイダーを確認します
2. **ビジネスへの影響を評価**：削除するプロバイダーがビジネスにとって重要かどうかを判断します
3. **特性の使用状況を評価する**：アクティブなセグメントに、影響を受けるデータプロバイダーの特性が含まれているかどうかを判断し、影響を受けないデータプロバイダーの類似の特性を見つけて、これらを置き換えます。
4. **必要に応じてAdobeにお問い合わせください**：特定のデータプロバイダーの削除について懸念がある場合は、お問い合わせください

## 実行すべき処理

### 影響を受けるデータプロバイダーを使用している場合 {#using-data-providers}

現在削除されているデータプロバイダーのいずれかを使用しており、業務運営に不可欠であると考えている場合：

1. **現在のオーディエンスセグメントとキャンペーンへの影響を評価**&#x200B;します。
2. **プロバイダーを維持するためのユースケース**&#x200B;とビジネス上の理由を文書化します。
3. **以下の情報を使用してAdobe**&#x200B;にお問い合わせください。

### 懸念がある場合 {#concerns}

これらの変更が事業運営に影響を与える可能性があることを理解しています。 データプロバイダーの削除について懸念がある場合は、Adobeにお問い合わせください。

## 連絡先情報 {#contact}

特定のデータプロバイダーの削除について話し合う必要がある場合、またはこれらの変更がビジネスにどのような影響を与えるかについて懸念がある場合は、以下のメールアドレスでAdobeにお問い合わせください。

**電子メール：** ampupdates@adobe.com

Adobeへのお問い合わせは、以下を含めてください。

* 組織名
* 関心のある特定のデータプロバイダー
* データプロバイダーの使用方法の簡単な説明
* このプロバイダーの削除によるビジネスへの影響

## よくある質問

### データプロバイダーが削除される理由？

「当社では、Audience Marketplaceを最適化して、お客様に最適な結果を提供するアクティブで価値の高いデータプロバイダーに注力しています。 これにより、マーケットプレイス体験をより合理化し、効果的に提供できます。

### データプロバイダーはどのように削除のために選択されましたか？

データプロバイダーは、利用パターン、顧客のエンゲージメントレベル、マーケットプレイス全体のパフォーマンス指標にもとづいて選択しました。

### これは、既存のオーディエンスセグメントに影響しますか？

削除されるデータプロバイダーを積極的に使用している場合、関連するオーディエンスセグメントに影響を与える可能性があります。 お客様のセグメントを確認し、懸念がある場合はお問い合わせください。

セグメントで削除されるデータプロバイダーの特性を使用している場合は、アクティブなデータプロバイダーの類似の特性にセグメントを置き換えて、それらの特性を更新する必要があります。 非アクティブなセグメントに対してアクションを実行する必要はありません。

### データプロバイダーを復元できますか？

特定のデータプロバイダーを維持するための強力なビジネスケースがある場合は、要件についてお問い合わせください。 個別に検討します。

### 変更はいつ施行されますか？

削除のために選択されたデータプロバイダーは、2025年8月に削除されます。
