# ヘルプと法的事項{#help-and-legal}

カスタマーケア、および本製品および本ドキュメントの使用に関連する法的事項に関するリソース。

* [問題がある場合](/help/using/help-legal/help-problem.md)
カスタマーサポートは、起こりうる問題の解決を支援する用意があります。 問題の理解および解決までの時間を短縮するために、できるだけこれらの情報をご用意したうえで、 カスタマーケアにご連絡ください。


* [連絡先と法的情報](/help/using/help-legal/help-legal-contact.md)
お客様がAdobeに連絡し、本製品およびドキュメントの使用に関する法的問題を理解するのに役立つ情報。
